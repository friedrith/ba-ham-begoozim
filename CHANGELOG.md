## [Unreleased]

### Added

- In-game feedback popup that emails bug reports, ideas and feedback ([#23](https://github.com/friedrith/ba-ham-begoozim/pull/23)).
- Wipeouts name the bean to blame, every bean gets an award, total stars earn a title, and the result can be shared as a picture ([#25](https://github.com/friedrith/ba-ham-begoozim/pull/25)).
- The menu shows how many people are playing online, once there are at least two ([#28](https://github.com/friedrith/ba-ham-begoozim/pull/28)).

### Fixed

## [0.1.0] - 2026-11-04

First version of the game.

### Added

- Couch co-op bathtub steering game, with four beans blasting from their own corners.
- Touch mode for playing on a shared iPad ([#5](https://github.com/friedrith/ba-ham-begoozim/pull/5)).
- Persian with right-to-left layout, and a language switcher ([#6](https://github.com/friedrith/ba-ham-begoozim/pull/6)).
- Nine harder levels, a frost theme and a tile menu ([#10](https://github.com/friedrith/ba-ham-begoozim/pull/10)).
- Swipeable menu carousel showing one level at a time ([#12](https://github.com/friedrith/ba-ham-begoozim/pull/12)).
- Online co-op with rooms, seats and prediction ([#13](https://github.com/friedrith/ba-ham-begoozim/pull/13)).
- Ba Ham Begoozim as the menu title ([#4](https://github.com/friedrith/ba-ham-begoozim/pull/4)).
- Link to the GitHub repo from the menu ([#8](https://github.com/friedrith/ba-ham-begoozim/pull/8)).
- Buy Me a Coffee links on GitHub and in the menu ([#14](https://github.com/friedrith/ba-ham-begoozim/pull/14)).
- Social media preview image and description ([#17](https://github.com/friedrith/ba-ham-begoozim/pull/17)).
- PostHog analytics for level funnels ([#11](https://github.com/friedrith/ba-ham-begoozim/pull/11)).
- Lint, typecheck, tests and build on every PR ([#3](https://github.com/friedrith/ba-ham-begoozim/pull/3)).
- Roadmap, and a link to the live game in the README.

### Fixed

- Ba Ham Begoozim used as the game name everywhere ([#9](https://github.com/friedrith/ba-ham-begoozim/pull/9)).
- Touch pads shrunk on tablets, so a touch near the middle no longer fires a blast ([#15](https://github.com/friedrith/ba-ham-begoozim/pull/15)).
- Sound plays on iOS when the ringer switch is on silent ([#18](https://github.com/friedrith/ba-ham-begoozim/pull/18)).
- Ba Ham Begoozim shown in the English tab title ([#19](https://github.com/friedrith/ba-ham-begoozim/pull/19)).
